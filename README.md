Public site for the Fr33zer PurrChas3 freezer-placement programme —
a Barks & Meows Only programme.

vendor shortlists, placement-fee figures, wholesale terms and internal
planning live outside it, in `~/Projects/Fr33zerPurrhcase/` and are not
tracked here. Nothing commercial-in-confidence belongs in this tree.

A mimic of this page lives on barksandmeowsonly.com. It is a mimic and
deliberately NOT a clone — thinner, links out here for detail — so the two
cannot drift into disagreeing about a number.
